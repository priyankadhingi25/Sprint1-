ADACTIN HOTEL APP - MANUAL TESTING PROJECT
===============================================

1. PROJECT OVERVIEW
-------------------
This project is a Manual Testing project for the Adactin Hotel Application.
The purpose of this project is to test the main functionalities of the hotel
booking application and verify that the application works as expected.

2. OBJECTIVE
------------
The main objectives of this project are:
- To understand the application requirements.
- To identify important testing scenarios.
- To create and execute manual test cases.
- To verify positive and negative test conditions.
- To validate login, hotel search, booking, and related functionalities.
- To identify defects during testing.
- To document the test results clearly.

3. APPLICATION UNDER TEST
--------------------------
Application: Adactin Hotel Application
Testing Type: Manual Testing
Testing Level: Functional Testing
Testing Approach: Black Box Testing

4. SCOPE OF TESTING
-------------------
The following major functionalities are covered:

- Login
- Hotel search
- Hotel selection
- Check-in and check-out date selection
- Room selection
- Guest details
- Hotel booking
- Booking confirmation
- Logout
- Validation and error messages

5. TESTING PROCESS
------------------
The testing process followed in this project is:

1. Understand the application requirements.
2. Identify test scenarios.
3. Prepare test cases.
4. Execute the test cases.
5. Compare actual results with expected results.
6. Record Pass/Fail status.
7. Report defects if found.
8. Prepare the final test report.

6. TEST CASES
-------------
The project contains 35 manual test cases covering different functional
areas of the Adactin Hotel Application.

Each test case contains details such as:
- Test Case ID
- Scenario ID
- Test Case Description
- Preconditions
- Test Steps
- Expected Result
- Actual Result
- Priority
- Status

10. TEST EXECUTION
------------------

The execution status was recorded as:
- PASS - Actual result matches the expected result.
- FAIL - Actual result does not match the expected result.
